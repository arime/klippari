# Klippari specification

This document describes what Klippari does. It is the source of truth:
when the code and this document disagree, one of them has a bug.

## Purpose

Klippari is a background app for macOS that remembers the last things
copied and pastes any of them from the keyboard. Ordinary copy and paste
are unaffected, and every step of invoking, selecting and pasting works
without the mouse.

## Platform

- macOS 15 or later. Swift 6 language mode. No third-party dependencies.
- Bundle identifier `com.arime.Klippari`, version 1.0.
- A background app: no Dock icon, a menu bar icon only.
- Not sandboxed, because pasting into other apps requires synthesizing
  keystrokes.
- Signed with a stable identity and always run from
  `/Applications/Klippari.app`. The Accessibility permission and the
  login item are tied to that signed bundle.

## Capturing

- The general pasteboard's change count is polled every 0.5 seconds.
- Whatever is on the clipboard when the app starts is not recorded.
- On a change, every pasteboard item is read with every type and its
  data. A copy of several files is one history item.
- A copy is not recorded when any type is one of the nspasteboard.org
  markers `org.nspasteboard.ConcealedType`,
  `org.nspasteboard.TransientType` or
  `org.nspasteboard.AutoGeneratedType`, or one of the older markers
  `com.agilebits.onepassword`, `de.petermaurer.TransientPasteboardType`,
  `com.typeit4me.clipping` or `Pasteboard generator type`. No data is
  read from such a copy.
- A copy over 20 MB in total is not recorded. Reading stops once the
  running total passes the cap.
- A type whose data cannot be read is dropped. The copy is dropped only
  when nothing is left.
- Each item records its capture time and the name of the app that was
  frontmost when it was captured.
- Copying content identical to an existing item (same types and bytes,
  compared by SHA-256) moves that item to the top instead of adding a
  duplicate. Its original capture time and source app are kept.
- The history keeps at most N items, 50 by default, and drops the
  oldest. Lowering N drops the excess at once.
- What the app itself puts on the clipboard when pasting is never
  recorded as a new copy.
- Capture can be paused. Nothing copied while paused is recorded, also
  not after resuming. Pause is not remembered across restarts.

## Storage

- History lives in `~/Library/Application Support/Klippari/items`,
  readable only by the user (mode 0700), and survives restart and
  logout.
- Each item has its own directory named by its identifier, containing:
  - `manifest.json`: identifier, capture time, last-used time, source
    app, image size and format if any, content hash, and for each
    pasteboard item the list of types with their data file names.
  - `e<item>-t<type>.bin`: the raw bytes of one type. File names come
    from indices, never from the type string.
  - `thumb.png`: for images only, at most 56 pixels on the longer side.
- An item is written to a temporary directory and renamed into place.
  On start, directories that are incomplete or unreadable are removed
  and the rest of the history loads.
- In memory, an item keeps only its plain text and file URLs. All other
  data is read from disk when the item is pasted.
- Moving an item to the top rewrites only its manifest.
- Items are ordered by last-used time, newest first.

## The panel

- Opened with the global shortcut. It takes keyboard focus without
  activating Klippari, so the app the user was in stays frontmost and
  receives the paste.
- It appears on the screen under the mouse pointer. Until it has been
  moved it is horizontally centred with its top edge a quarter of the
  way down the screen.
- It can be dragged by any part of the card that is not a control. The
  spot it is left in is remembered across restarts as a position
  relative to the screen, so it reopens in the same relative place on
  whichever screen is in use. The card is always kept fully on screen.
- Each time it opens the list is scrolled so the selected row is in
  view.
- It closes when it loses focus.
- It follows the system light or dark appearance, using a native blur
  material and the system font.

Layout, top to bottom, in a card 640 points wide with 14-point corners:

- Filter field with a magnifier glyph, the placeholder 'Type to
  filter', and a count on the right: '50 items', '1 item', or '2 of 50'
  while filtering.
- The list: rows 44 points high, at most 9 visible (every row
  that Cmd+1 to Cmd+9 can paste), scrolling to keep
  the selection in view.
- A strip of key hints: Return 'Paste', Shift+Return 'Paste as plain
  text', Cmd+1–9 'Quick paste' on the left; Cmd+Backspace 'Delete' and
  esc 'Close' on the right. A notice replaces the hints when there is
  something to say.

Each row has four lanes:

1. Number, 1 to 9 for the first nine visible rows, blank after that.
2. An icon for the kind of item, or a thumbnail for an image.
3. The title on one truncated line, followed by a grey tag.
4. Source app name, left-aligned, and age, right-aligned. The app
   column is as wide as the longest name shown, up to 110 points.

The selected row is the only coloured element: blue `#0A5CFF` with
white text, the same blue as the app icon.

Row content, first match wins:

| Item | Title | Tag |
| --- | --- | --- |
| One or more files | File name, or 'N files' | 'file' |
| Image data (PNG or TIFF) | 'Image' | '1280 × 720 · PNG' |
| Text that also has RTF or HTML | First non-empty line | 'styled' |
| Text that is a single http(s) URL | The URL | none |
| Other text | First non-empty line | 'N lines' when more than one non-empty line |
| Anything else | The type's readable name | none |

Ages read 'now' under a minute, then 'N min', 'N h', 'N d'.

With no history the list shows 'Nothing copied yet'. With a filter
that matches nothing it shows 'No matches'.

## Keyboard

| Key | Effect |
| --- | --- |
| Shift+Cmd+V (configurable) | Open the panel with the newest item selected and the filter focused. Pressed again while open, move the selection down. |
| Up / Down, Ctrl+P / Ctrl+N | Move the selection. It stops at either end. |
| Return | Paste the selected item as it was copied. |
| Shift+Return | Paste it as plain text. An item with no text form is pasted as copied. |
| Cmd+1 to Cmd+9 | Paste that row of the visible list, as copied. |
| Any typing | Edit the filter. |
| Cmd+Backspace | Remove the selected item from the history. The selection moves to the next row, or the previous one at the end. |
| Esc | Clear a non-empty filter; otherwise close the panel without pasting. |

The filter matches case-insensitively against an item's text, its file
names and its source app name. The first match becomes selected and
rows are renumbered.

If something is copied while the panel is open, the list updates and
the selection stays on the same item.

## Pasting

- The item's full content is read from disk and written to the general
  pasteboard, the panel closes, and 50 milliseconds later Cmd+V is
  posted to the system.
- A plain-text paste writes only the item's plain string. The history
  item keeps its styled form.
- When an item has image data and no text, its HTML type is left out
  of the paste. Browsers attach an HTML fragment that only points at
  the remote original, and rich text views that prefer it can block
  while fetching it. The stored item keeps the HTML.
- The pasted item becomes the current clipboard content and moves to
  the top of the history.
- Posting Cmd+V requires the Accessibility permission. Without it the
  item is still put on the clipboard, the panel stays open with the
  notice 'Copied. Grant Accessibility in System Settings to paste
  directly.', and the system permission prompt is shown once per
  install.

## Menu bar

- The icon is the app icon's three rows as a monochrome template
  image, so macOS tints it for light and dark menu bars. It is dimmed
  while capture is paused.
- Menu: Pause Capture / Resume Capture, Clear History, Reset Panel
  Position, Settings… (Cmd+,), Quit Klippari (Cmd+Q).
- Reset Panel Position forgets where the panel was dragged to, so it
  opens in its default place again.
- Clear History asks for confirmation, then removes every item from
  memory and disk.

## Settings

- **History size**: 5 to 500 items, 50 by default.
- **Shortcut**: recording starts on Return, Space or a click in the
  field, and Esc cancels. A shortcut needs Cmd, Ctrl or Option. Cmd
  alone with A, Z, X, C, V, Q or W, and Shift+Cmd+Z, are refused,
  because a global shortcut swallows its keystroke in every app. If a
  shortcut cannot be registered, the previous one is kept and the
  field says so.
- **Start at login**: on by default. The app registers itself once, on
  first launch, and only when running from `/Applications`. The toggle
  turns it off or on.

History size, shortcut and panel position are stored in the app's
preferences.

## App icon

Three rounded rows on a near-black rounded square: the top row blue
`#0A5CFF`, the two below in receding greys. It is the panel in
miniature. `Scripts/make-icon.swift` draws it at every size.

## Building and testing

- `Scripts/build-app.sh` builds a release, assembles and signs
  `Klippari.app`, installs it to `/Applications` and launches it.
  `--no-install` stops after building. The signing identity must be
  given, with `--identity <name>` or the `CODESIGN_IDENTITY`
  environment variable; none is stored in the repository, and the
  script stops with an error without one.
- `swift test` runs the unit tests of the core library, which holds
  everything that does not need a window: capture rules, storage,
  history, row presentation, filtering and panel state.
- `docs/manual-checklist.md` lists the checks that need a person at
  the Mac.
- `Klippari --snapshot <png> [dark] [--query <text>]` renders the
  panel with sample items to an image, for checking its layout. Adding
  `settings` renders the settings window's content instead.

## Not included

- Sync between machines.
- Pinned items, snippets, or editing an item's content.
- Excluding particular apps from capture.
- Selecting or pasting rows with the mouse.
- App Store distribution.
